# Objective
The primary goal is to build an interactive, web-based AI assistant using Retrieval-Augmented Generation (RAG) to make the Cambodian Road Traffic Law easily accessible in the Khmer language.

### Specific Objectives:
- Collect, clean, and segment official Cambodian Road Traffic Law documents in Khmer.
- Convert legal text chunks into high-dimensional vector representations (1024 dimensions) using a multilingual transformer model (such as bge-m3).
- Implement an Information Retrieval system using Cosine Similarity to match user queries with relevant legal articles.
- Integrate a Large Language Model (LLM) to generate accurate, easy-to-read Khmer answers citing the exact legal articles.
- Build a user-friendly web interface for citizens to submit questions and view answers along with source references.
- Design the system architecture so it can be easily expanded to other Cambodian legal domains (e.g., Labor Law, Civil Code) in the future.
